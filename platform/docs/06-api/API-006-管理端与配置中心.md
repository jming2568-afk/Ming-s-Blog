# API 契约 — 管理端与配置中心（V0.03）

> 全局约定见 [API-001](API-001-契约总则.md)。本域属 P5/P5.5（进行中），契约为 draft。
> **守卫**：以下全部接口需登录（401）且 `role === "admin"`，否则 `403` `无权限`。

## `/api/admin` 管理端（P5）

### GET `/api/admin/users`

- 成功：`200 {ok, users: [...]}`——每项含 `id / username / email / displayName / role / themeId / createdAt / resumeCount(简历数)`
- 排序：`createdAt` 降序；上限 200 条（当前无分页参数）

### GET `/api/admin/users/:id/resumes`

- 成功：`200 {ok, resumes: [{id, title, slug, isPublic, updatedAt}]}`（`updatedAt` 降序）
- `400` `无效 ID`

## `/api/admin/config` 配置中心（P5.5）

额外限流：**30 次/用户/分钟**（超限 429）。配置优先级：DB（加密存储）> env；保存空值即删除 DB 项回退 env。

### GET `/api/admin/config`

- 成功：`200 { ok: true, masterKeyOk: boolean, config: [...] }`
  - `config`：配置项列表，**密钥打码展示**并标注来源（DB/env）
  - `masterKeyOk`：加密主密钥是否已配置（未配置时敏感项无法解密/保存）

### PUT `/api/admin/config`

- 请求：`{ config: [{ key: string, value: string }] }`（最多 50 项，upsert 语义；value 为空删除该项回退 env）
- 成功：`200 {ok:true}`
- `400` 校验失败 / 不允许修改的键 / master key 问题
- `500` 其他保存失败

### POST `/api/admin/config/test-llm`

用当前合并配置向 LLM 发送极短探针（"请只回复：ok"）。

- 成功：`200 { ok, latencyMs, protocol, model, reply }`
- `400` `LLM 未配置（LLM_API_KEY 或 ARK_API_KEY 为空）`
- `502` `LLM 测试失败: <原因>`（含 latencyMs）

### POST `/api/admin/config/test-storage`

对对象存储做「写入探针 → 删除探针」连通性测试。

- 成功：`200 { ok, latencyMs, endpoint, bucket, pathStyle }`
- `400` `存储未配置（STORAGE_ENDPOINT/AK/SK/BUCKET 不完整）`
- `502` `存储测试失败: <原因>`（含 latencyMs）
