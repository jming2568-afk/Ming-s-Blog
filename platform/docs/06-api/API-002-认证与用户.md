# API 契约 — 认证与用户（V0.03）

> 全局约定（响应包络/鉴权/限流/错误码）见 [API-001](API-001-契约总则.md)。校验 schema 唯一事实源：`packages/shared/src/validation/auth.ts`（Zod，前后端共用）。

## `/api/auth` 认证（P2）

### POST `/api/auth/register`

注册并**直接建立会话**（注册即登录）。

- 限流：10 次/IP/分钟（超限 429 `注册过于频繁，请稍后再试`）
- 请求：`{ username, email, password }`

| 字段 | 规则 |
|---|---|
| `username` | 3–20 字符；仅字母/数字/下划线/连字符/中文 |
| `email` | 合法邮箱，≤120 字符 |
| `password` | 8–72 位 |

- 成功：`201 {ok, user}` + `set-cookie: sid=...`（HttpOnly，30 天）
- `400` 请求格式/校验失败（error 为 Zod 首条 message）
- `409` 用户名或邮箱已被占用
- 附注：注册后执行 `syncRoleIfAdmin`，命中管理员规则时同步为 admin 角色

### POST `/api/auth/login`

- 限流：20 次/IP/分钟（超限 429 `尝试过于频繁，请稍后再试`）
- 请求：`{ username, password(≥1) }`
- 成功：`200 {ok, user}` + `set-cookie: sid=...`
- `401` 用户名不存在或密码错误
- `400` 校验失败

### POST `/api/auth/logout`

- 无需 body；销毁服务端会话并置空 cookie（Max-Age=0）
- 成功：`200 {ok:true}`

### GET `/api/auth/me`

- 成功：`200 {ok, user}`
- `401` `未登录`

## `/api/users` 用户资料（P3）

以下接口均**需登录**（未登录 401）。

### GET `/api/users/me`

- 成功：`200 {ok, user}`（当前登录用户完整资料）

### PUT `/api/users/me`

- 请求：`{ themeId?: number | null, displayName?: string(≤50) }`
- 语义：字段可选，仅更新出现的键；`themeId: null` 表示清除主题选择
- 成功：`200 {ok, user}`（更新后的用户记录）
- `400` 校验失败 / `主题不存在`（themeId 无效）

## user 对象（响应中统一形态）

来自 `users` 表记录，主要字段：`id`、`username`、`email`、`displayName`、`role`（`user` | `admin`）、`themeId`、`createdAt`。
