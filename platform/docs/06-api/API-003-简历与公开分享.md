# API 契约 — 简历与公开分享（V0.03）

> 全局约定见 [API-001](API-001-契约总则.md)。简历数据结构（`ResumeData`）与发布完整性规则（`isPublishable`）定义于 `packages/shared/src/validation/resume.ts`，前后端共用。

## `/api/resumes` 简历 CRUD（P3）

以下接口均**需登录**，且资源按 `userId` 隔离（只能操作自己的简历）。

### GET `/api/resumes`

- 成功：`200 {ok, resumes: [...]}`（当前用户全部简历）

### POST `/api/resumes`

- 请求：`{ title?: string(≤100) }`，缺省 `未命名简历`
- 成功：`201 {ok, resume}`
- `400` 校验失败

### GET `/api/resumes/:id`

- 成功：`200 {ok, resume}`
- `400` `无效 ID`（非数字）
- `404` `未找到`（不存在或不属于当前用户）

### PUT `/api/resumes/:id`

- 请求：`{ title?: string(≤100), slug?: string(≤64), data?: object }`（均可选，部分更新）
- 成功：`200 {ok, resume}`
- `400` 无效 ID / 校验失败
- `404` `未找到`
- `409` `slug 已被占用`（SlugTakenError）

### POST `/api/resumes/:id/publish`

- 请求：`{ isPublic: boolean }`
- 行为：`isPublic: true` 时先做 `isPublishable(data)` 完整性校验，不通过则拒绝发布
- 成功：`200 {ok, resume}`（含新的 `isPublic` 状态；下架 `isPublic:false` 无完整性要求）
- `400` 无效 ID / 请求格式错误 / `简历不完整，无法发布`（含具体 reason）
- `404` `未找到`

### DELETE `/api/resumes/:id`

- 成功：`200 {ok:true}`
- `400` 无效 ID；`404` `未找到`

## `/api/themes` 主题（P3）

### GET `/api/themes`（公开，无需登录）

- 成功：`200 {ok, themes: [{id, name, tokens, isSystem}]}`
- 数据库未配置时返回 `{ok:true, themes: []}`（不报错）

## `/api/public` 公开分享（P3）

### GET `/api/public/resumes/:slug`（公开，仅已发布简历）

分享页 `/r/:slug` 的数据源。

- 成功：`200 {ok, resume}`——resume 含简历数据与 `owner`（昵称等），并在 `owner.theme` 附带主人所选主题的 `{id, name, tokens}`（前端直接注入 CSS 变量）
- `404` `简历不存在或未发布`
