# API 契约总则（V0.03）

> 适用范围：`platform/apps/api`（Hono 服务，version `0.3.0`）。**不适用于** V0.02 根目录 Next.js API（其契约见根 `docs/API契约.md`）。
> 本文是各域契约文档（API-002 ~ API-006）的公共基础；修改全局中间件/错误处理时必须同步更新本文。

## 基础信息

| 项 | 值 |
|---|---|
| 实现 | Hono（`apps/api/src/app.ts`） |
| 路由前缀 | `/api/*` |
| 健康检查 | `GET /api/health` → `{ok, service:"api", version:"0.3.0", time, db:"configured"|"not-configured"}` |
| 数据库 | SQLite（Drizzle），未配置时业务接口抛 500 |

## 响应包络（强制）

- **成功**：`{ "ok": true, ...业务字段 }`
- **失败**：`{ "ok": false, "error": "人类可读信息" }` + 对应 HTTP 状态码
- **统一兜底**：
  - 未处理异常 → 500 `{ok:false, error:"服务器内部错误"}`（`app.onError`）
  - 路由不存在 → 404 `{ok:false, error:"接口不存在"}`（`app.notFound`）
- **例外**：`GET /api/export/word/:slug` 成功时返回 docx 二进制流（见 API-004）

## 鉴权（cookie 会话）

- 会话 cookie：`sid`，HttpOnly、SameSite=Lax、Path=/、Max-Age 30 天；生产环境附加 Secure
- **全局可选认证**（`authOptional`）：所有请求尝试解析用户挂到 context，未登录不拦截
- **登录守卫**（`requireAuth`）：未登录/会话失效 → 401 `{ok:false, error:"请先登录"}`
- **管理端守卫**：`role !== "admin"` → 403 `{ok:false, error:"无权限"}`（见 API-006）

## CORS（动态配置）

- 来源白名单从配置中心读取（DB 优先，回退 env），命中则回显 Origin，否则不同源
- `credentials: true`（携带 cookie）

## 安全响应头（全路由）

| Header | 值 |
|---|---|
| `X-Content-Type-Options` | `nosniff` |
| `X-Frame-Options` | `DENY` |
| `Referrer-Policy` | `strict-origin-when-cross-origin` |
| `X-XSS-Protection` | `0` |

## 限流（内存滑动窗口）

实现：`RateLimiter`（`modules/auth/rate-limit.ts`），单实例内存方案；**多实例部署需换 Redis/DB**。超限统一 429。

| 域 | 键 | 限额 |
|---|---|---|
| 注册 | IP | 10 次/分钟 |
| 登录 | IP | 20 次/分钟 |
| AI（polish/import） | 用户 ID | 10 次/分钟 |
| 配置中心 | 用户 ID | 30 次/分钟 |

## 错误码约定

| 状态码 | 语义 | 典型场景 |
|---|---|---|
| 200/201 | 成功（创建类用 201） | 注册、新建简历、上传媒体 |
| 400 | 请求格式/校验失败 | Zod 校验失败、缺字段、文件超限/类型不符、简历不完整不可发布 |
| 401 | 未登录 | 会话缺失或失效 |
| 403 | 无权限 | 非 admin 访问管理端 |
| 404 | 资源不存在 | 简历不存在、未发布、接口不存在 |
| 409 | 资源冲突 | 用户名/邮箱已占用、slug 已被占用 |
| 429 | 限流 | 各域超频 |
| 500 | 服务器内部错误 | 未处理异常、数据库/对象存储未配置 |
| 502 | 上游服务失败 | LLM 调用失败、LLM/存储连通性测试失败 |
| 503 | 能力未配置 | LLM 未配置（`LLM_API_KEY`/`ARK_API_KEY` 为空） |
