# API 契约 — 媒体与导出（V0.03）

> 全局约定见 [API-001](API-001-契约总则.md)。本域属 P4（交付与媒体，进行中），契约为 draft，随实现演进更新。

## `/api/media` 媒体上传（P4）

### POST `/api/media`（需登录，multipart/form-data）

上传头像/证书等**图片**至对象存储（TOS/MinIO S3 兼容），返回公网直链。

- 表单字段：`file`（必填）
- 限制：
  - 大小 ≤ **8MB**（超限 400 `文件过大（最大 8MB）`）
  - MIME 白名单：`image/jpeg`、`image/png`、`image/webp`、`image/gif`、`image/svg+xml`（其他 400 `仅支持图片（jpeg/png/webp/gif/svg）`）
- 成功：`201 {ok, media: { key, url, mime, size } }`
  - 存储路径规则：`media/{userId}/{uuid}.{ext}`，同时在 `media` 表登记记录
- `400` 缺少文件字段 / 超限 / 类型不符
- `500` `对象存储未配置：请设置 STORAGE_ENDPOINT / STORAGE_ACCESS_KEY_ID / STORAGE_SECRET_ACCESS_KEY / STORAGE_BUCKET`（预期守卫，属配置问题）

## `/api/export` 导出（P4）

### GET `/api/export/word/:slug`（需登录）

导出**本人**简历为 Word（docx，可编辑）。

- **成功响应为二进制流**（唯一的非 JSON 成功响应）：
  - `Content-Type: application/vnd.openxmlformats-officedocument.wordprocessingml.document`
  - `Content-Disposition: attachment; filename="<URL编码的简历标题>.docx"`
- `404` `简历不存在`（不存在或不属于当前用户——按 slug + 所有权查询）

### PDF 导出说明

按 TECH-001 §4.2：**服务端不生成 PDF**，由客户端 `window.print()` + `@media print` 完成打印/另存 PDF；调用方勿在此添加服务端 PDF 接口。
