# PRD — 简历一站到底（V0.03）

> 产品需求文档 · 简历公开平台（创建 · 展示 · 交付 一体化）
> 状态：active ｜ 更新：2026-08-15 ｜ 关联：V0.02（已冻结，Vercel 专用版）

---

## 1. 产品概述

### 1.1 定位

> **「简历一站到底」**：用户在线创建/导入简历 → 生成专属链接展示给 HR → 随时导出一致的 Word / PDF / 纸质打印件。**线上看到什么，打印出来就是什么。**

从 V0.02（个人简历站，单管理员）升级为**公开简历平台**：多用户注册、各自编辑简历、各自生成专属分享链接；所有计算与存储由平台方托管，小规模试运行（约 20 人）。

### 1.2 目标用户

| 角色 | 说明 | 核心诉求 |
|---|---|---|
| 简历主人（求职者） | 注册用户 | 快速创建/导入简历、AI 辅助、一键分享、面试前打印不出错 |
| 访客（HR / 面试官） | 点开链接的人 | 移动端快速阅读、信息结构清晰、可打印/保存 |
| 打印店老板 | 收到链接的第三方 | 打开链接 → 直接打印出合格 A4 简历，无需排版沟通 |

### 1.3 背景与动机

- 传统简历痛点：Word 排版痛苦、格式跨设备错乱、投递格式不兼容、面试打印要重新排版、简历迭代维护繁琐。
- V0.02 验证了"专属链接展示个人页"的模式（Memphis 风格），V0.03 将其产品化、多用户化，并补齐**导入（AI）**与**交付（导出/打印）**两端。

## 2. 三板块业务模型

### 板块 A：创建与导入（Create & Import）— "10 秒进编辑器"

| 子能力 | 用户价值 | 优先级 |
|---|---|---|
| 结构化编辑器 | 分节填写（基本信息/简介/工作经历/项目/教育/技能/证书），实时预览，自动保存 | P0 |
| AI 写作助手 | 写经历时按 STAR 法则润色、按岗位 JD 优化措辞、补技能标签 | P1 |
| AI 旧简历导入 | 上传 Word / PDF / **扫描件图片** → OCR + LLM 结构化提取 → 自动填充编辑器草稿（可人工改） | P1 |
| 多格式导入 | 支持 docx / pdf / 常见图片 | P1 |

### 板块 B：展示与分享（Showcase & Share）— "一张名片式主页"

| 子能力 | 用户价值 | 优先级 |
|---|---|---|
| 专属链接 `/r/:slug` | HR 点链接直达用户自己设计的简历页 | P0 |
| 多主题 | 5 套风格主题（Memphis 复古 / 极简黑白 / 莫兰迪 / 科技渐变 / 奶油暖色），用户可选 | P0 |
| 移动优先 | 微信等移动端阅读体验优先 | P0 |
| 发布控制 | 发布/下架、自定义 slug、重新生成链接 | P0 |

### 板块 C：导出与交付（Export & Deliver）— "打印店场景零摩擦"

| 子能力 | 用户价值 | 优先级 |
|---|---|---|
| 直接打印 | 面试前把链接发给打印店老板（或扫码），老板点打印即出合格 A4 简历 | P0 |
| PDF 导出 | 投递用标准 PDF | P0 |
| Word 导出 | 公司强制要 docx 时可编辑版 | P1 |
| 二维码 | 链接转二维码，扫码即开 | P1 |

## 3. 核心卖点

1. **三端同源一致**：线上链接 / PDF / 纸质打印**完全同版式**——面试打印零翻车，打印店零沟通成本（最独特卖点）。
2. **AI 旧简历导入**：上传 Word/PDF/扫描件 → 10 秒结构化进编辑器（多模态 LLM OCR + 提取）。
3. **AI 写作助手**：STAR 润色、按岗位 JD 优化、补技能词，写简历不再从零开始。
4. **名片式专属主页**：多主题、移动优先的简历展示页（继承 V0.02 Memphis 血统）。
5. **零摩擦交付**：链接/二维码直达打印店；无需 Word/WPS/第三方工具，浏览器点打印即合格件。

## 4. 用户旅程

### 4.1 主人（核心）
```
注册/登录 → 工作台 → （导入旧简历[AI] 或 空白新建）
→ 编辑器分节填写 + AI 助手 → 选主题（实时预览）
→ 发布 → 生成专属链接 /r/:slug → 复制链接/二维码
→ 投递：发 PDF / 链接；面试：链接发打印店 → 打印 A4
→ 随时回编辑器改，改完自动生效；可下架/删除
```

### 4.2 访客（HR/面试官）
```
收到链接 /r/:slug → 按主人主题移动优先阅读 → 底部 CTA（联系方式/打印）
→ 打印 = 浏览器打印 / 另存 PDF（A4 优化，与线上同版式）
```

### 4.3 打印店
```
收到链接（或二维码）→ 打开 → 点打印 → A4 合格件交付，无需沟通排版
```

### 4.4 平台侧（P5）
```
/admin 管理员登录 → 用户列表（活跃/封禁）、简历列表（违规处理）
```

## 5. 信息架构（路由）

```
公开侧（无需登录）
├── /                      # 平台 Landing：价值主张 + 示例简历 + 注册/登录入口
├── /login  /register      # 认证（同版式切换）
└── /r/:slug               # 公共分享页（按主人主题渲染）

├── /app/resumes/:id/preview  # 全屏预览（发布前访客视角自查）
└── /app/settings          # 个人设置：资料/头像/密码/默认主题

管理侧（P5 可选）
└── /admin                 # 用户/内容管理
```

## 7. 主题系统需求

- **主题 = 设计令牌**（CSS 变量：颜色/字体/圆角/间距/阴影/纹理），只换皮肤不动布局。
- MVP 5 套风格主题；**布局模板二期**（一期统一布局，保证编辑器与打印复杂度可控）。
- 用户主题存 `users.theme_id`；未登录选择记忆 localStorage。
- 公共页按主人主题渲染；主题被下架 → 回退默认主题（容错）。
- 主题卡片墙预览：用 tokens 渲染迷你简历示意。

## 8. 一致性内核需求（灵魂约束）

- **同源渲染引擎**：一套 React 布局组件（`packages/ui/resume-layout`）同时服务三种输出：
  - 展示页 `/r/:slug`（屏幕，响应式）
  - 打印（`@media print`，A4 分页）
  - PDF（服务端无头浏览器打印同源组件）
- 验收硬指标：展示页与打印/PDF 输出**版式一致**（无交互元素、A4 分页正确、不换字体不回行错乱）。
- 任何新增样式必须三端同时验证（P3 起纳入验收）。

## 9. 非功能需求

| 项 | 要求 |
|---|---|
| 容量 | 20 人试运行；2C4G VPS；单 API 容器 + 单 PostgreSQL + TOS 对象存储 |
| 性能 | 公共页首屏 < 2s；编辑器保存 < 1s（防抖） |
| 安全 | 密码 bcryptjs；会话可撤销；注册限流；CORS 白名单；LLM 密钥仅服务端 |
| 部署 | Docker Compose（nginx + web 静态 + api + postgres）；GitHub Actions CI/CD |
| 备份 | pg_dump 定时 + TOS 媒体 |
| 镜像体量 | 自定义镜像压缩后 ≤ ~150MB（多阶段构建 + 生产依赖裁剪） |

## 10. 里程碑规划

| 里程碑 | 范围 | 验收 |
|---|---|---|
| P1 骨架 | monorepo + web/api/shared/ui 空壳 + compose + 健康检查 + 测试骨架 | `/api/health` 通；web 构建过；compose 起三服务 |

| P6 上线 | VPS 部署、域名/HTTPS、TOS 生产、备份、20 人内测 | 线上全流程可用、数据有备份 |

## 12. 范围外（Out of Scope）

- 简历内容的多语言翻译、视频简历
- 求职者与企业招聘平台对接（职位投递闭环）
- 移动 App / 小程序（一期仅 Web 响应式）
- 简历数据导出为其他平台格式（如拉勾/猎聘模板）
- 平台级计费、多租户隔离的复杂权限（试运行期单租户平台）
